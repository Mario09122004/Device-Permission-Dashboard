Privacy Guidance & Architecture

Key Guarantee: “Local educational experiment — no data is uploaded or recorded.”

1. How Browser Permissions Work

Modern browsers employ a strict sandbox security architecture. Web pages cannot access cameras, microphones, or geolocation sensors without explicit user interaction and affirmative consent.

2. Immediate Camera Stream Termination

When you click Check camera permission, a temporary stream is requested solely to verify device capability. The instant the promise resolves, our code calls stream.getTracks().forEach(track => track.stop()). No canvas is drawn, no snapshot taken, and no video feed is rendered or kept in memory.

3. Zero-Coordinate Location Privacy

When you click Request location permission, the application strictly captures whether the browser returned success or failure. The numerical latitude, longitude, altitude, and precision properties are never read or stored.

4. Refusal is First-Class

Denying requests is completely normal and supported. The application handles NotAllowedError and PERMISSION_DENIED gracefully without degraded dashboard functionality.
